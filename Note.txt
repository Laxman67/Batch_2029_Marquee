***** Reading and Checking Directory******
1.   List contents: Use fs.readdir() or fs.readdirSync() to get
  an array of all file and folder names inside a directory.

Optional: { withFileTypes: true } :

Get detailed content info: Pass { withFileTypes: true } inside readdir to get Dirent objects. This lets you immediately check if an item is a file or a subdirectory using .isFile() or .isDirectory()


2.Folder Existence :  Use fs.existsSync(path,()=>{}) to check if a directory path is valid



****Modifying and Moving Directories*****

1. : Use fs.rename() or fs.renameSync() to change a folder's name
