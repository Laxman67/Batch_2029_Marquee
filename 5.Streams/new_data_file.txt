Streams

Streams are objects in Node.js that efficiently handle data flow, especially when dealing with large datasets. Large excel , vedio, audio, text file, csv file


Understanding Streams

Streams are collections of data that can be read or written as chunks, rather than loading the entire data set into memory.
They enable efficient processing of data by allowing us to operate on small portions of data at a time.
•	Useful when dealing with large files or network communication like Images , Vedios, Large JS File Chunks,


Streams can be categorized into 4 types:
•	Readable Streams represent a source from which data can be read.
•	Writable Streams represent a destination where data can be written.
•	Duplex Streams can be both readable and writable.
•	Transform streams are a special type of duplex stream that can modify or transform the data while it is being read or written.
Real-World Example
